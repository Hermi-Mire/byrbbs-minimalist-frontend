# 北邮人论坛 · 简约版

Tampermonkey 用户脚本，把北邮人论坛的**帖子详情页**重做成响应式卡片布局：楼层更宽松、阅读区更专注，同时保留原站的全部功能。当前版本 **0.7.0**，只作用于 `#!article/...` 帖子页，默认开启；左下角「简约版」或 `Alt+M` 可随时切回原版。

## 功能

### 阅读与布局

- **卡片楼层**：头像、用户名、正文和底部操作重新排版，缩放页面时精彩回复不再被裁切。
- **浮动标题 / 路径栏**：向下滚动显示当前主题，向上滚动显示版面路径，点击主题回到顶部。
- **底部快捷回复**：固定在窗口底部；滚到页尾后底部工具栏回到最后一张卡片之后。
- **深色模式**：可手动切换或跟随系统。
- **发信信息折叠**：每层默认只显示「发信站」，点行尾小箭头展开完整发信人 / 标题。
- **窄屏适配**：窄窗口下头像变成卡片顶部的横向信息条；匿名版面（IWhisper）没有头像内容时自动隐藏头像栏。

### 交互

- **头像即资料入口**：取消「查看」按钮，点击头像打开重新排版过的用户资料框。
- **楼主标记**：与楼主同 ID 的楼层会在楼层徽标后追加「楼主」。
- **简化赞 / 踩**：减少弹窗提醒，但主贴赞踩状态刷新才显示。
- **收藏**：帖子页一键收录。取消收藏请到站点的「我的收录文章」里操作。
- **「只看此ID」**：精彩回复和匿名板块补上了「只看此ID」入口；匿名帖 ID 含 `#`，已修正链接编码。
- **版面菜单**：左下角 `☰` 打开完整版面列表，不跳转侧边栏。
- **原站功能保留**：搜索、关注、分页、分享、回复、精彩回复、只看此 ID、返回顶部等。

## 安装

**一键安装**：[点此安装](https://raw.githubusercontent.com/Hermi-Mire/byrbbs-minimalist-frontend/main/byrbbs-minimalist-frontend.user.js)（Tampermonkey 会弹出安装页）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击上面的安装链接，或打开 [`byrbbs-minimalist-frontend.user.js`](byrbbs-minimalist-frontend.user.js) 后选择 “Raw”
3. Tampermonkey 弹出安装页后点击「安装」

手动安装：Tampermonkey 控制面板 → 新建脚本 → 粘贴 `byrbbs-minimalist-frontend.user.js` 的全部内容 → 保存。

安装后打开任意帖子详情页，左下角出现「简约版」按钮即生效。

## 使用

- **切换经典版**：左下角控制条的「简约版」，或按 `Alt+M`。
- **切换主题**：左下角控制条的主题按钮，可选跟随系统 / 浅色 / 深色。

## 注意事项

- 只影响帖子详情页，其他页面保持不变。
- 依赖站点现有 DOM 和 CSS，站点改版后可能失效；布局异常时按 `Alt+M` 切回经典版。
- 主要在离线保存页上验证，线上 AJAX 细节可能略有差异。
- 与其他修改版面的用户脚本可能冲突，可暂时停用其中一个。
- **网络与隐私**：脚本不会自动发起任何网络请求。只有在你主动点击赞 / 踩 / 收藏时，才会沿用站点自身的 AJAX 接口提交这一次操作；不会读取或上传账号密码、Cookie、帖子内容，也不会自动发帖、回复或点赞。界面偏好只保存在 `localStorage` 的 `bym-enabled` / `bym-theme` 中。
